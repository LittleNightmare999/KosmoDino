# Диаграммы системы «КосмоДино»

Курсовой проект по дисциплине «Программная инженерия»: Гуляева Анастасия Павловна, группа 25-КБ-ПИ1.

Готовые изображения лежат в `png/`, исходные тексты — в `src/`: файлы `.dot` для Graphviz и `.puml` для PlantUML.

| № | Файл | Диаграмма | Методические указания |
| --- | --- | --- | --- |
| 1 | `01_kontekstnaya_dfd.png` | Контекстная диаграмма потоков данных | ЛР 3 |
| 2 | `02_dfd_uroven_0.png` | Диаграмма потоков данных нулевого уровня | ЛР 3 |
| 3 | `03_perehody_sostoyaniy.png` | Диаграмма переходов состояний статьи с составным состоянием | ЛР 4, рисунок 6 |
| 4 | `04_strukturnaya_shema.png` | Структурная схема (иерархия модулей) | ЛР 5 |
| 5 | `05_funkcionalnaya_shema.png` | Функциональная схема по ГОСТ 19.701-90 | ЛР 5 |
| 6 | `06_shema_dannyh.png` | Схема данных в третьей нормальной форме | ЛР 6 |
| 7 | `07_algoritm_modulya.png` | Схема алгоритма модуля «Изменить состояние статьи» | ЛР 7 |
| 8 | `08_varianty_ispolzovaniya.png` | Диаграмма вариантов использования | ЛР 11 |
| 9 | `09_deyatelnost.png` | Диаграмма деятельности с суперсостоянием | UML, ЛР 4 рисунок 6 |
| 10 | `10_klassy.png` | Диаграмма классов | ЛР 12 |
| 11 | `11_posledovatelnost_vhod.png` | Диаграмма последовательности «Регистрация и вход» | UML |
| 12 | `12_posledovatelnost_publikaciya.png` | Диаграмма последовательности «Рецензирование статьи» | UML |
| 13 | `13_razvertyvanie.png` | Диаграмма развёртывания (размещения) | UML |

Перестроить все диаграммы (нужны Docker и Node.js; один раз выполнить `npm install` в каталоге `tools`):

```
powershell -File uml\tools\render.ps1
```
